CODA — anonymous supplementary material

Open index.html in a current desktop browser. JavaScript and WebGL are required for interactive 3D; the CODA replay videos are also available in videos/.

Everything runs offline. Keep this folder together when using index.html. The separately supplied single-file HTML contains all assets in one file.

15 selected observations: 6 HomebrewedDB and 9 custom scenes. Compare CODA with ASTRA, SAM3D, RecGen, or ZeroGrasp using the method selector. Drag to orbit, scroll to zoom, and right-drag to pan. Both methods share the same camera and simulation time. Observed RGB points start enabled and can be toggled off.

Reconstruction shows saved predicted surfaces. Retention replays existing evaluation states. CODA videos show its recorded test at normal speed. Custom ASTRA is available only on Scene7/frame24 and Scene29/frame88, for reconstruction; a retention replay under the current custom protocol is unavailable.

Selected observations are qualitative examples. Dense display meshes and measured points are subsampled; evaluation sources and scores are unchanged. Third-party licenses are included.

Figure 2 presents the complete CODA pipeline above the interactive examples. Select Expand figure to inspect its labels at full size; Escape or the close button closes the figure.

The Figure 7 diversity section includes a supplementary shelf example: mustard bottle and shelf soup can, eight saved CODA and RecGen completions each. Select a seed, inspect observed or hidden regions, toggle observed RGB points or ground truth, and orbit/zoom with a shared camera. GT-best is an oracle selection using ground truth. Fit all samples includes distant fragments beyond Object view.
